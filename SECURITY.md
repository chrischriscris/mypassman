# Security policy

The replacement is in its design phase and is unaudited. The archived
implementation is also unaudited. Report vulnerabilities privately rather
than opening a public issue with sensitive details.

Use GitHub's private vulnerability reporting for this repository, or contact
the maintainer through the GitHub profile. Include the affected branch and
commit, component, reproduction, and whether the report comes from a working
exploit or source review. Do not include real vault credentials in public reports.

Keep advisory scope explicit: design reviews, automated tests, and implementation
security audits provide different evidence. Any published fix should state the
behavior corrected and the versions affected. No bounty program is configured.
